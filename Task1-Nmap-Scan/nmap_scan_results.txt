5. OPEN PORT ANALYSIS (23 open ports)
=====================================================
Risk levels: LOW / MEDIUM / HIGH / CRITICAL

PORT 21 - FTP - vsftpd 2.3.4 - CRITICAL
  What it does: File transfer between machines.
  Risk: This exact version contains a known backdoor (CVE-2011-2523).
  Credentials and files are also sent unencrypted.

PORT 22 - SSH - OpenSSH 4.7p1 - MEDIUM
  What it does: Encrypted remote login and file transfer.
  Risk: SSH itself is secure, but this version is very outdated and has
  known vulnerabilities. Weak passwords can be brute-forced.

PORT 23 - Telnet - Linux telnetd - HIGH
  What it does: Remote terminal access.
  Risk: Sends everything, including passwords, in plain text. Anyone on
  the network can capture it. Replace with SSH.

PORT 25 - SMTP - Postfix smtpd - MEDIUM
  What it does: Sends and routes email.
  Risk: Can leak valid usernames, and may be abused as a spam relay if
  misconfigured.

PORT 53 - DNS - ISC BIND 9.4.2 - MEDIUM
  What it does: Translates domain names to IP addresses.
  Risk: Outdated version with known flaws such as cache poisoning and
  denial of service.

PORT 80 - HTTP - Apache httpd 2.2.8 - HIGH
  What it does: Serves web pages.
  Risk: Outdated web server hosting deliberately vulnerable web apps.
  Traffic is unencrypted.

PORT 111 - rpcbind - RPC #100000 - MEDIUM
  What it does: Maps RPC services to ports (used by NFS).
  Risk: Reveals which RPC services run, helping attackers plan.

PORT 139 - NetBIOS-SSN - Samba smbd 3.X-4.X - HIGH
  What it does: Legacy Windows file and printer sharing.
  Risk: Old Samba versions have serious remote code execution flaws.

PORT 445 - SMB - Samba smbd 3.X-4.X - HIGH
  What it does: Modern Windows file sharing over SMB.
  Risk: Same as 139. SMB is a very common attack target.

PORT 512 - exec - netkit-rsh rexecd - HIGH
  What it does: Remote command execution (r-service).
  Risk: Old, unencrypted, and relies on weak trust-based authentication.

PORT 513 - login - rlogin - HIGH
  What it does: Remote login (r-service).
  Risk: Plain-text and trust-based; easy to abuse. Replace with SSH.

PORT 514 - shell - tcpwrapped - HIGH
  What it does: Remote shell (rsh).
  Risk: Same weaknesses as 512 and 513. No encryption.

PORT 1099 - Java RMI - GNU Classpath grmiregistry - HIGH
  What it does: Lets Java programs call methods on remote machines.
  Risk: Misconfigured RMI registries can allow remote code execution.

PORT 1524 - bindshell - Metasploitable root shell - CRITICAL
  What it does: A backdoor shell left on purpose.
  Risk: Anyone who connects gets a root shell with no password.
  Complete system compromise.

PORT 2049 - NFS - RPC #100003 - HIGH
  What it does: Network file sharing for Unix/Linux.
  Risk: Misconfigured exports can expose files to anyone.

PORT 2121 - FTP - ProFTPD 1.3.1 - MEDIUM
  What it does: A second FTP server.
  Risk: Outdated version, plain-text credentials, extra attack surface.

PORT 3306 - MySQL 5.0.51a - HIGH
  What it does: Database server.
  Risk: Databases should never be exposed to the network. Old version,
  often weak or empty root password.

PORT 5432 - PostgreSQL 8.3.0-8.3.7 - HIGH
  What it does: Database server.
  Risk: Exposed and outdated, with a default or weak password.

PORT 5900 - VNC (protocol 3.3) - HIGH
  What it does: Remote desktop control.
  Risk: Weak password authentication and no strong encryption.

PORT 6000 - X11 - access denied - MEDIUM
  What it does: Linux graphical display server.
  Risk: Currently denies access, but exposing X11 can allow screen
  capture and keystroke logging if access control is weak.

PORT 6667 - IRC - UnrealIRCd - CRITICAL
  What it does: Internet chat server.
  Risk: Some versions contain a known backdoor (CVE-2010-2075) that
  allows remote command execution.

PORT 8009 - AJP13 - Apache Jserv (protocol v1.3) - MEDIUM
  What it does: Connector between a web server and Apache Tomcat.
  Risk: Should never be exposed externally; can be abused to reach
  the Tomcat backend.

PORT 8180 - HTTP - Apache Tomcat/Coyote JSP engine 1.1 - HIGH
  What it does: Java web application server.
  Risk: Admin pages are often left with default credentials, allowing
  attackers to deploy malicious applications.

=====================================================
6. OVERALL ASSESSMENT
=====================================================
23 open ports were found. Most services are outdated, unencrypted, or
have known backdoors. This is expected: Metasploitable2 is built to be
vulnerable for training. A real system should close unused ports, patch
software, replace Telnet/FTP/r-services with SSH/SFTP, restrict
databases to localhost, and use a firewall.
