## Task 4: Common Network Security Threats

### Objective

To understand common network security threats, their effects, and the methods used to prevent them.

### Topics Covered

1. **DoS and DDoS Attacks** – Attacks that make websites or online services unavailable.
2. **Man-in-the-Middle (MITM) Attacks** – Attacks that intercept communication between two parties.
3. **IP Spoofing** – Using a forged IP address in network traffic.
4. **DNS Poisoning and Spoofing** – Manipulating DNS information to redirect users to incorrect destinations.

### Key Learning Outcomes

* Understand common network security threats.
* Identify the possible effects of cyberattacks.
* Learn basic methods for protecting networks and information.
* Understand the importance of firewalls, secure DNS, monitoring, and multi-factor authentication.
